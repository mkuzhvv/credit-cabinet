# Общий запуск в Docker

Здесь размещается конфигурация совместного запуска компонентов проекта.

## Содержимое

- `compose.yaml` — общий Compose-файл; добавляется вместе с конфигурацией сервисов.
- `.env.example` — пример переменных окружения без секретов.
- При необходимости — настройки прокси и вспомогательных сервисов.

`Dockerfile` каждого приложения размещаем рядом с его исходниками: `backend/Dockerfile`, `frontend/Dockerfile` и в соответствующем компоненте `ml/`.

Пути `build.context` в `compose.yaml` должны учитывать расположение файла: например, `../backend` и `../frontend`.

## Команда запуска

После добавления `compose.yaml` общий запуск из корня репозитория будет выполняться так:

```bash
docker compose -f docker/compose.yaml up --build
```

Вместе с Compose-конфигурацией добавь сюда требования к окружению, настройку переменных, адреса интерфейсов, тестовые аккаунты, команды остановки и способы проверки готовности сервисов.
