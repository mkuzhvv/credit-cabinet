# Бэкенд

Здесь размещается Java-бэкенд проекта.

## Содержимое

- HTTP API для фронтенда и интеграций.
- Бизнес-логика заявок, проверок, решений и предложений.
- Работа с БД, миграции и синтетические тестовые данные.
- Интеграции с ML-компонентами и имитаторами внешних сервисов.
- Конфигурация сборки, тесты и `Dockerfile` бэкенда.

## Инструкция по запуску

При добавлении приложения укажи здесь версию Java, команды сборки, запуска и тестирования, переменные окружения, порт и адрес документации API.

Общие контракты и схемы размещаются в [docs/](../docs/README.md), конфигурация совместного запуска — в [docker/](../docker/README.md).
