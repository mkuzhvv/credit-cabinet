# Фронтенд

Здесь размещается веб-кабинет предпринимателя: каталог, заявка, помощник и результат рассмотрения.

[Backend OpenAPI](../docs/contracts/backend.openapi.yaml). Общие правила, сессия и примеры: [руководство по контрактам](../docs/contracts/README.md).

## Содержимое

- Страницы, формы, компоненты и стили.
- Клиент для обращения к API бэкенда.
- Тесты интерфейса и пользовательских сценариев.
- Конфигурация сборки, lock-файл зависимостей и `Dockerfile` фронтенда.

## Инструкция по запуску

Инструкция должна содержать версию среды, пакетный менеджер, команды установки зависимостей, запуска, сборки и тестирования, порт и настройку адреса API.

Контракты API размещаются в [docs/](../docs/README.md), конфигурация совместного запуска — в [docker/](../docker/README.md).

## Поле остатка средств — Backend API 0.5.0

В ApplicationForm добавлено cashBalance — «Свободные собственные деньги». Передаётся строкой RUB с двумя знаками после точки, например "1000000.00", либо null в неполном черновике. Это доступные собственные средства до нового кредита; неизвестное значение нельзя заменять нулём. При отправке заявки поле обязательно для всех пяти продуктов. Ноль допустим и будет оценён формальной политикой Python.

PUT формы по-прежнему заменяет объект целиком: обязательны все девять ключей amount, termMonths, averageMonthlyInflow, averageMonthlyOutflow, financingPurpose, projectBudget, trancheTermMonths, governmentContract, cashBalance. Неприменимые/незаполненные значения — null. Старые черновики получают cashBalance=null. Остальные URL, сессия, CSRF и денежный формат сохранены. В этой ветке исходников интерфейса пока нет; поле нужно добавить при подключении актуального frontend.
