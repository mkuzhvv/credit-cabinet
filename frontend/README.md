# Умный кредитный кабинет предпринимателя — Frontend

Клиентская часть веб-приложения (SPA) для подбора бизнес-кредитов, предварительного расчёта финансовой нагрузки и подачи онлайн-заявок для ИП и ООО в рамках проекта «Альфа Бизнес».

---

## Основные возможности

### 1. Витрина кредитных продуктов (`ProductsPage.jsx`)
* **Лендинг-баннер и ключевые параметры** — быстрый переход к подбору кредита или оформлению заявки, сводка по линейке (лимит до 10 млн ₽, срок до 60 месяцев, ставка от 21% годовых, без залога и комиссий).
* **Интерактивный навигатор («Как выбрать подходящий продукт»)** — 5 карточек с типовыми бизнес-задачами, которые при клике автоматически выделяют нужный кредитный продукт и плавно прокручивают страницу к каталогу.
* **Каталог из 5 кредитных продуктов** — адаптивная сетка карточек одинакового размера с полным отображением названий и параметров:
  1. *Оборотный кредит* 
  2. *Овердрафт* 
  3. *Возобновляемая кредитная линия*
  4. *Кредит на длительный срок*
  5. *Кредитная линия на госконтракт* 
* **Модальное окно «Подробнее»** — детальная карточка продукта с условиями погашения, требованиями к заёмщику, практическими примерами и блокировкой прокрутки фоновой страницы при открытии.
* **История заявок («Ваши недавние заявки»)** — секция в нижней части витрины для быстрого возврата к ранее созданным черновикам и отправленным анкетам.

### 2. Оформление заявки и скоринг (`ApplicationPage.jsx`)
* **Интерактивная анкета с автосохранением** — ввод суммы и срока кредита (числовые поля и ползунки `range`), среднемесячных поступлений и расходов, а также дополнительных полей оборудования для продукта `EQUIPMENT`.
* **Финансовый калькулятор в реальном времени** — автоматический расчёт ориентировочного ежемесячного платежа по аннуитетной формуле и чистого денежного потока (доходы минус расходы) с цветовой индикацией нагрузки.
* **Контроль версий (`Optimistic Locking`)** — отслеживание версии заявки (`v1`, `v2`...) и автоматическое разрешение конфликтов (`VERSION_CONFLICT`) при сохранении.
* **Поддержка всех 6 статусов жизненного цикла заявки:**
  * `DRAFT` — редактируемый черновик заявки.
  * `CHECKING` — экран автоматической проверки с опросом сервера (polling) каждые 2 секунды.
  * `APPROVED` — экран положительного решения с одобренными условиями (сумма, срок, ставка, график погашения).
  * `DECLINED` — экран отказа с детализацией причин и кодов решения.
  * `NEEDS_INFO` — сценарий дозапроса данных при нулевых поступлениях (подтверждение нулевого оборота с комментарием либо исправление суммы в анкете).
  * `TECHNICAL_HOLD` — экран технической паузы при сбое внешнего сервиса оценки с возможностью повторной отправки (`Retry`) без потери данных.
* **Демо-пульт тестирования состояний OpenAPI** — панель быстрого переключения статусов (`1. Черновик`, `2. Одобрено`, `3. Отказ`, `4. Уточнение 0 ₽`, `5. Тех. сбой`) для удобной демонстрации всех пользовательских сценариев.

### 3. Шапка и навигация (`Header.jsx`)
* **Переключатель разделов** — вкладки «1. Продукты» и «2. Заявка» с динамическим цветным бейджем текущего статуса открытой заявки.
* **Переключатель режима API** — смена источника данных на лету между **«Моки OpenAPI»** (автономная работа в браузере) и **«Java API (/api/v1)»** (работа с бэкенд-сервером).
* **Кнопка «Недавние заявки»** — быстрый переход и плавный скролл к списку последних заявок из любой точки приложения.

### 4. Умный помощник (`AssistantWidget.jsx`)
* Встроенный виджет-ассистент, подсказывающий правила заполнения полей и помогающий сравнить условия кредитных продуктов.

## Технологический стек

* **Фреймворк:** React 18 (Hooks: `useState`, `useEffect`, `useRef`)
* **Сборщик:** Vite 5
* **Стилизация:** Tailwind CSS 3, PostCSS, Autoprefixer, кастомные CSS-анимации (`fadeIn`, `float`)
* **Иконки:** Lucide React (`lucide-react`)
* **Контроль качества кода:** ESLint 9

## Установка и запуск

### 1. Предварительные требования
Убедитесь, что на компьютере установлен **Node.js** версии **18.x** или выше (вместе с пакетным менеджером `npm`).

### 2. Установка зависимостей
Перейдите в директорию фронтенда и установите пакеты:

```bash
cd frontend
npm install
```

### 3. Запуск сервера для разработки
Стандартный запуск локального dev-сервера Vite:

```bash
npm run dev
```

Запуск с открытием доступа по локальной сети:

```bash
npm run dev -- --host
```

После запуска откройте в браузере адрес: `http://localhost:5173/`

### 4. Сборка для продакшена
Для компиляции и минификации проекта в папку `dist/` выполните:

```bash
npm run build
```

Для локальной проверки собранной продакшен-версии:

```bash
npm run preview
```

## Режимы работы и интеграция с Backend

Приложение поддерживает два режима работы, которые переключаются кнопкой в правом верхнем углу шапки:

1. **Режим «Моки OpenAPI» (`mock`)** — используется по умолчанию для быстрой демонстрации. Все данные о продуктах, сохранение черновиков, расчёт скоринга и переключение статусов через демо-пульт обрабатываются локально в браузере в полном соответствии с контрактом OpenAPI.
2. **Режим «Java API (/api/v1)» (`real`)** — фронтенд отправляет реальные HTTP-запросы к бэкенду. В файле `vite.config.js` настроен dev-прокси, который автоматически перенаправляет все запросы с префиксом `/api` на `http://localhost:8080`, предотвращая ошибки CORS.
