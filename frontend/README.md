# Фронтенд

Здесь размещается веб-кабинет предпринимателя: каталог, заявка, помощник и результат рассмотрения.

[Backend OpenAPI](../docs/contracts/backend.openapi.yaml). Общие правила, сессия и примеры: [руководство по контрактам](../docs/contracts/README.md).

## Содержимое

- Страницы, формы, компоненты и стили.
- Клиент для обращения к API бэкенда.
- Тесты интерфейса и пользовательских сценариев.
- Конфигурация сборки, lock-файл зависимостей и `Dockerfile` фронтенда.

## Инструкция по запуску

Инструкция должна содержать версию среды, пакетный менеджер, команды установки зависимостей, запуска, сборки и тестирования, порт и настройку адреса API.

Контракты API размещаются в [docs/](../docs/README.md), конфигурация совместного запуска — в [docker/](../docker/README.md).
