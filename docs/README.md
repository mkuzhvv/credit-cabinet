## Контракты

[Справочник контрактов](contracts/README.md) связывает HTTP API и форматы данных:

- [Backend OpenAPI 0.5.0](contracts/backend.openapi.yaml).
- [Scoring OpenAPI 0.4.0](contracts/scoring.openapi.yaml), признаки версии `4`.
- [LLM: контекст v2 и ответ v1](contracts/llm/README.md), JSON Schema и контрольные вопросы.

В запущенном приложении Swagger доступен по `/swagger-ui/index.html`, сформированная Java спецификация — по `/v3/api-docs`.

## Источники конфигурации

- [compose.yaml](../compose.yaml) — сервисы и контейнерные адреса.
- [application.yaml](../backend/src/main/resources/application.yaml) — значения по умолчанию, бюджеты и закреплённая версия скоринга.
- [Миграции Flyway](../backend/src/main/resources/db/migration/) — фактическая структура и начальные данные.
- [Конфигурация помощника](../backend/src/main/resources/assistant/config.json) — модель, digest, промпт и генерация.
- [Политика Python](../ml/scoring/policy.json), [каталог расчёта](../ml/scoring/catalog.json), [схема признаков](../ml/scoring/schema.json).

Изменение контракта, условий, алгоритма или модели требует согласованного обновления реализации, примеров и документации. Исторические описания этапов разработки не используются как инструкция запуска.
