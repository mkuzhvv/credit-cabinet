# Документация

Общие договорённости команды и материалы для проверки решения.

## Материалы по бэкенду

1. [Архитектура и стек](BACKEND_ARCHITECTURE.md) — структура кода, демосессия, интеграции и фоновая обработка.
2. [Сценарии и принятые решения](BACKEND_SCENARIOS.md) — состояния, правила поведения и тонкости реализации.
3. [Контракты API и LLM](contracts/README.md) — Backend OpenAPI, Scoring OpenAPI, JSON-схемы и требования LLM.
4. [Кредитная политика и требования к ML](CREDIT_POLICY_AND_ML_REQUIREMENTS.md) — демопродукты, правила решения, уточнение нулевых поступлений, подбор порога и результаты ML-команды.

Основные документы находятся в этой папке. Контракты размещены в `contracts/`; модель данных добавляется по мере проектирования.

## Что размещать здесь

- Требования и согласованные границы MVP.
- Архитектурную схему и модель данных.
- Диаграмму состояний заявки и правила переходов.
- Описание правил кредитного решения и демонстрационных допущений.
- Контракты API: OpenAPI, схемы ML-запросов и ответов, коллекцию запросов.
- Тестовые сценарии, сценарий демонстрации и результаты проверки.
- Принятые решения по спорным вопросам с датой и причиной выбора.

Инструкции по сборке и отдельному запуску компонентов хранятся рядом с их кодом. Общий запуск описывается в [docker/README.md](../docker/README.md).
