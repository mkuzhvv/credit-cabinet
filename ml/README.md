# Компоненты ассистента и кредитной политики

- [llm/README.md](llm/README.md) — локальный LLM-ассистент для объяснения продуктов и полей.
- [scoring/README.md](scoring/README.md) — формальная денежная политика и внутренний HTTP-сервис для Java. Обучение и синтетический скоринг удалены.

Компоненты независимы: кредитная проверка работает без LLM и Ollama. Ассистент не определяет одобрение заявки.
