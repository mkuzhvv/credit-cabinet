# ML-компоненты

Здесь размещается код моделей и их интеграции с продуктом.

## Содержимое

- Подготовка данных, обучение и оценка моделей.
- Модель скоринга и её HTTP-сервис для Java-бэкенда.
- Промпты и конфигурация языкового помощника, запускаемого через Ollama.
- Схемы признаков, синтетические примеры запросов и ожидаемых ответов.
- Зафиксированные зависимости и `Dockerfile` сервиса, если он нужен.

Если компонентов несколько, разделяем их по назначению, например `scoring/` и `assistant/`.

## Инструкция по запуску

При добавлении компонента опиши его назначение, версии модели и среды, способ получения артефактов, команды запуска, требования к памяти/CPU/GPU, контракт входа и выхода, метрики и ограничения применения.

Контракт с бэкендом размещается в [docs/](../docs/README.md), конфигурация совместного запуска — в [docker/](../docker/README.md).
